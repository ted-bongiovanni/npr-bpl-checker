Design Notes

Key Change: The three-way mode toggle (Read / Listen / Surprise Me) replaces format as a primary navigation choice. "Surprise Me" shows one ebook + one audiobook side by side.

Mode Behaviors

  • 📖 Read: Shows 3 ebooks from NPR Books We Love (current behavior)
  • 🎧 Listen: Shows 3 audiobooks from AudioFile Earphones Awards
  • ✨ Surprise Me: Shows 1 ebook + 1 audiobook (best of both worlds)

Visual Distinctions

  • Format badges: Blue "eBook" vs orange "Audiobook"
  • Award badge: Gold 🏆 for Earphones Award winners
  • Cover backgrounds: Light gray for ebooks, dark gray for audiobooks
  • Narrator line: Orange accent showing narrator name
  • Narrator review: Quoted excerpt from AudioFile about the narration

Settings Toggle Changes

  • "Seriously Great Writing only" → "Award Winners only" (applies to both sources)
  • For ebooks: filters to NPR's "Seriously Great Writing" tag
  • For audiobooks: all are award winners by definition

Availability Status

  • Shows both counts: "223 ebooks + 47 audiobooks available"
  • Single refresh button updates both

Data Sources

  • eBooks: NPR Books We Love (2020-2025) - existing
  • Audiobooks: AudioFile Earphones Awards (2020-2025) - new
  • Both checked against Brooklyn Public Library OverDrive
Implementation Challenge: AudioFile doesn't have a public API. We'll need to scrape their monthly awards pages (they give ~16 awards per month). The data includes title, author, narrator(s), genre, publisher, and a review excerpt.

New Files Needed

  • scrape-audiofile.js - Scrape Earphones Awards by year/month
  • check-audiobook-availability.js - Check BPL audiobook availability
  • audiobooks.json - Scraped audiobook data
  • available-audiobooks.json - Available audiobooks at BPL

Button Text by Mode

  • Read: "✨ Find Books" → "🔄 Spin Again"
  • Listen: "🎧 Find Audiobooks" → "🔄 Spin Again"
  • Surprise Me: "✨ Surprise Me" → "🔄 Surprise Me Again"
